---
description: Record what happened to a tracked application
---

Update `job_search_tracker.csv` and the application's archive with a
result.

## Steps

1. Ask which application (company + role) and what happened: no response,
   rejection, moved to next stage, offer, or declined offer.
2. Update the matching row in `job_search_tracker.csv` with the status and
   date.
3. If there's useful detail (interviewer feedback, why rejected, offer
   terms), append it as a short note in
   `documents/applications/<company>_<role>/outcome.md`.
4. If several applications have gone quiet (no response after ~10
   business days) and the candidate hasn't followed up, ask whether they'd
   like a short, honest follow-up message drafted — using only claims from
   materials already submitted, and only drafted, never sent
   automatically.
5. If an offer came in or several outcomes have landed, offer to review
   `04-job-evaluation.md`'s rubric with the candidate — real interview
   feedback is a good moment to recalibrate what "fit" should weigh going
   forward.
