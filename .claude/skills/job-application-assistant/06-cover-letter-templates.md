# Cover Letter Template Rules

The cover letter lives at `cover_letters/cover_example.tex`, using the
custom `cover.cls` class. Compile with `xelatex` (the class requires
`fontspec`).

## Hard limits

- **Exactly 1 page.** If a draft runs long, cut paragraph length before
  cutting font size — a cramped-looking letter reads worse than a slightly
  shorter one.
- Signature block must render visibly on the page (not pushed off by
  overflow).
- Fonts must match the CV (Lato/Raleway, per `OpenFonts/` in
  `cover_letters/`).

## Structure

1. **Opening** — something specific to this company/role, never a generic
   "I am writing to apply for..."
2. **Why this role fits** — 1-2 sentences connecting the candidate's real
   background to what the posting is asking for.
3. **Proof point** — one concrete example from the candidate's actual work
   history that demonstrates the fit claimed above.
4. **Close** — brief, confident, states interest in next steps.

## Rules

- Every claim must trace back to `01-candidate-profile.md`. Never invent an
  achievement or exaggerate scope to sound better.
- Tailor to the specific company — reference something real about them
  (mission, product, recent news) found via `/apply`'s research step, and
  verify it before using it.
- Match tone rules in `03-writing-style.md`.
