# documents/

Drop your source material here before running `/setup` — Claude will read
it instead of asking you to retype everything.
documents/
├── cv/ # Your current CV as PDF or .tex
├── linkedin/ # LinkedIn "Download your data" export (PDF or ZIP)
├── diplomas/ # Degree certificates / transcripts (optional)
├── references/ # Reference letters (optional)
└── applications/ # Auto-populated by /apply — one folder per
# <company>_<role> with the posting, CV, cover
# letter, and outcome notes for that application
